# 15. 三数之和

> [原题链接](https://leetcode.cn/problems/3sum/)

## 描述

给你一个整数数组 nums ，判断是否存在三个元素 a，b，c ，使得 a + b + c = 0 ？
如果存在所有满足条件且不重复的三元组。

注意：答案中不可以包含重复的三元组。

## 思路

1.数组先排序，方便双指针缩小范围 + 跳过重复元素
2.固定第一个数 nums[i]，左指针 j=i+1，右指针 k=nums.length-1
3.三数和分三种情况：

- 和 = 0：存入结果，同时跳过左右重复值
- 和 < 0：左指针右移，增大和
- 和 > 0：右指针左移，减小和
4.外层循环跳过相同的 nums[i]，避免重复三元组

## 代码

```javascript
function threeSum(nums) {
    const res = [];
    const len = nums.length;
    if (len < 3) {
        return res;
    }

    // 排序
    nums.sort((a, b) => a - b);

    for (let i = 0; i < len - 2; i++) {
        if (i > 0 && nums[i] === nums[i - 1]) {
            continue;
        }
        let j = i + 1;
        let k = len - 1;
        while (j < k) {
            const sum = nums[i] + nums[j] + nums[k];
            if (sum === 0) {
                res.push([nums[i], nums[j], nums[k]]);
               
                while (j < k && nums[j] === nums[j + 1]) {
                    j++;
                }
                while (j < k && nums[k] === nums[k - 1]) {
                    k--;
                }
                j++;
                k--;
            } else if (sum < 0) {
                j++;
            } else {
                k--;
            }
        }
    }
    return res;
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(logn)
